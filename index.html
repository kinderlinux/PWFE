Kurulum

İki komut. Sonra tarayıcı.

Arch Linux için hazırlanmış kurulum betiği bağımlılıkları kontrol eder, servisleri kurar ve arayüzü açar. Kaynağı kendin derlemek istersen README yanında.

  1. 01

    Depoyu çek

    Kaynak kodu klonla. Tek ihtiyacın git.

  2. 02

    Kur

    install.sh bağımlılıkları kurar, binary'leri derler, systemd birimlerini yazar.

  3. 03

    Tarayıcıyı aç

    Yerel IP ve 7933 portuna git. Ayarlar'dan paylaşacağın klasörleri seç.

README'yi oku ↗
bash — ~/pwfe
$git clone https://github.com/kinderlinux/PWFE.git
$cd PWFE
$sudo ./install.sh
# → http://<yerel-ip>:7933

Son

Dosyaların seni bekliyor.
